# MediPulse - Medical Web Application

## Overview

MediPulse is a fullstack medical web application designed to streamline healthcare management. It is built with **React** and **TypeScript** on the frontend, and **Node.js**, **Express**, and **SQL** on the backend. The application provides secure JWT-based authentication and authorization, CRUD operations for managing medical data, and features an integrated chatbot to assist patients and healthcare providers. The frontend is deployed on **Vercel**, and the backend is hosted on **Railway**.

---

## Technologies Used

- **Frontend:**
  - React
  - TypeScript
  - Redux
  - Context API
  - Vercel (deployment)

- **Backend:**
  - Node.js
  - Express
  - SQL (MySQL/PostgreSQL/Other)
  - JWT Authentication & Authorization
  - Railway (deployment)

- **Key Features:**
  - Patient and healthcare data management with CRUD operations
  - Secure authentication and role-based authorization
  - Integrated chatbot for medical assistance and user support
