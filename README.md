## 🚀 Overview

**MediPulse** is a fullstack medical web application designed to streamline healthcare management.

🧠 Built with:  
**React + TypeScript** (Frontend)  
**Node.js + Express + SQL** (Backend)  

☑️ Features:  
- Secure **JWT** authentication & role-based authorization  
- CRUD operations for managing medical data  
- Integrated chatbot for patient assistance  
- Hosted on **Vercel (Frontend)** & **Railway (Backend)**

## 🩺 Key Features

- ✅ Patient & doctor management with full CRUD
- 🔐 Secure login/signup with JWT
- 👨‍⚕️ Role-based access: Admin / Doctor / Patient
- 🤖 AI Chatbot for fast medical support
- 📊 Clean dashboard with real-time data (React, Redux)
- 🌐 Deployed with CI/CD pipeline using Railway & Vercel
